# OneShot 성장 비교

실행 환경: Roblox Studio 편집 모드 Luau. 제출 빌드의 GrowthConfig/GrowthMath/GameConfig를 require한 결정적 시뮬레이션이다. 실행 마커는 [Studio 계산 로그](test-logs/oneshot-compare.studio.log)와 [CSV](oneshot-compare.csv)다. 아래 모의 행은 실제 Play 보스 클리어 기록이 아니다.

모든 경로는 초기 수련력 0, Gold 0, 돌파 1단계, 시설 1등급, 장비 없음으로 시작한다. 자동사냥 경로는 8킬/분을 가정하고 모든 경로가 비용이 충족되면 같은 시설 구매 정책을 따른다. Gold는 몬스터별 최소·최대값의 평균을 사용한다. 드롭·장비 교체·재도전·피격·실제 이동 시간은 계산에서 제외했다. 무료 자동사냥과 두 모의 성장권 경로만 동일한 사냥·시설 정책이다. 기본 무료 수련은 별도 기준선이다.

관문 클리어 시간은 Gate10/20/30 전투에 각각 60/90/120초를 가정한 수치다. 실제 클리어 시간은 측정 전이므로 표시하지 않는다. 모든 경로에서 관문은 직접 클리어했다고 가정한 뒤에만 다음 단계 계산을 이어간다.

같은 사냥·시설 정책의 Gate10 도달 시간은 무료 9:49, +5권 6:41, 10분권 7:57이다. 차이는 각각 3:08, 1:52이며 관문 전투 가정 1분은 모든 경로에 동일하게 적용했다. 이 차이는 경쟁작 공식이 아니라 IdleRaid의 현행 수식과 명시한 킬 속도 가정에서 나온다.

시설 유료권은 현재 정의가 없으므로 모의 비교에 포함하지 않았다. 실제 상품 ID·가격도 없고 판매는 비활성이다.

## 제출 빌드에서 실제로 수행한 무료 Play

[동일 제출 파일](build-manifest.json)을 연 Studio Play 세션에서 정상 프로필로 시작했다. 사냥으로 Gold를 얻고 ClothArmor를 획득해 비교·장착했으며, Gold 120으로 시설 2등급을 샀다. UI에서 무료 +1 돌파를 반복해 Gate10에 도달했고 Slime King을 직접 클리어했다.

| 측정 | 실제 시간/결과 |
| --- | --- |
| Gate10 도달 | 시작 후 294초 (4:54) |
| Raid 시작 | 시작 후 약 299초 |
| Boss 실제 전투 | 107.2초 (1:47.2) |
| Gate10 실제 클리어 | 시작 후 406초 (6:46) |
| 패턴/피격 | Ground Slam 12회, Charge 11회, 피격 0회 |

[Studio Play CreatorOutput 발췌](test-logs/oneshot-free-play.studio.log)에 `IR_FREE_SERVER_RESULT true`와 `RaidMetrics Clear`가 있다. 이 실측 경로는 장비 드롭·실제 이동/킬 속도·회피를 포함한다. 위 계산표는 초당 고정 적 처치율과 가정 보스 시간을 쓰므로 그 수치와 직접 동일 조건으로 간주하지 않는다. 모의 유료 경로의 **실제** 관문 클리어 시간은 측정하지 않았다.
