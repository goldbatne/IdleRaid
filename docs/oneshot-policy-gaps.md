# 정책·외부 권한으로 남은 항목

| ID | 현재 사실 | 다음 결정의 영향 |
| --- | --- | --- |
| R08 상품 | ProductId·Robux 가격이 없고 실제 판매는 OFF다. 현재 코드에는 보유 권리 사용과 Studio 모의 영수증 처리만 있다. | 실제 구매 요청·가격 조회·운영 영수증 경로는 상품 계약과 ID 승인 후 별도 구현·검증이 필요하다. |
| 유료 시설 | 유료 시설 권리, 지급 대상, 중복 처리 계약이 없다. 무료 Gold 시설만 존재한다. | 임의 상품이나 가격을 만들지 않는다. |
| R10 Charge | 보스 이동 종료 시 전체 경로 선분으로 서버 피격 판정을 한다. | 이동 중 접촉 판정으로 바꿀지 종료 시점 공격으로 표시할지 결정이 필요하다. Damage·속도·무적 시간은 변경하지 않았다. |
| R11 Defense | 장비 Defense는 표시·스탯 합산까지만 적용된다. 현재 보스 피해 감소식은 없다. | 피해 감소 공식을 정하기 전에는 방어구가 생존력을 높인다고 안내하지 않는다. |
| R12 지역 효율 | 기존 비교 모델은 단계에 맞는 최고 지역 적을 8킬/분으로 처치한다고 가정한다. 실제 AutoCombat은 거리상 가장 가까운 살아 있는 적을 고른다. | 약한 적이 특정 단계에서 유리할 수 있다. 실제 처치 간격과 지역 선택을 수집한 뒤 지역 고정·가중 타깃 설계를 결정한다. 보상·HP는 변경하지 않았다. |
| 운영 저장 | Studio는 메모리 모의 저장소다. 게시 서버 DataStore 잠금 경쟁·종료 후 재접속은 미검증이다. | 별도 비운영 환경에서 영구 저장 회복을 검증해야 한다. |
| 모바일 실기 | 모바일 공격 버튼과 중앙 조준 Raycast 코드를 추가했다. | 실제 기기에서 조이스틱·카메라·메뉴와의 터치 충돌 및 가독성 검증이 남았다. |

원본 경제 수치, 돌파 비용, 관문 간격, 보스 수치, 상품 가격은 이번 안정화에서 변경하지 않았다.
