# IdleRaid 성장 통합 v2 검증 기록

기준 코드: `codex/growth-v2-integration` 브랜치의 Rojo 빌드. 검증일: 2026-10-08. 이 문서의 “통과”는 명시한 환경에서 직접 실행한 항목만 뜻한다.

## 실행 환경

- Roblox Studio 0.742.0.7421053, Windows. `rojo build default.project.json`로 만든 임시 `.rbxlx`를 `StudioTestService:ExecutePlayModeAsync`로 실행했다.
- Studio 프로필은 `ProfileStore`의 메모리 모의 저장소를 사용한다. 게시 서버 DataStore를 읽거나 쓰지 않았다.
- 실제 결제 요청과 Robux 지출은 실행하지 않았다. ProductId와 가격은 모두 미설정이고 구매 UI는 비활성 상태다.
- 기존 사용자 `IdleRaid.rbxl`을 열거나 저장하는 자동 테스트는 수행하지 않았다.

## 성장 경로 비교

`docs/growth-v2-economy.csv`의 각 관문 클리어 행을 사용한다. 시간은 초이며 각 경로의 보스 전투에 60/90/120초를 **가정**해 합산했다. 자동사냥 8킬/분, 직접 플레이 10킬/분도 실측값이 아닌 비교 가정이다. 직접 플레이와 자동사냥 모두 같은 시설 구매 정책을 사용한다.

| 경로 | Gate10 클리어 | Gate20 클리어 | Gate30 클리어 | 사용권 |
| --- | ---: | ---: | ---: | --- |
| 무료 기본 수련 | 1,005초 (16:45) | 3,560초 (59:20) | 7,645초 (127:25) | 없음 |
| 무료 자동사냥+시설 | 651초 (10:51) | 1,867초 (31:07) | 3,251초 (54:11) | 없음 |
| 직접 플레이+시설 가정 | 619초 (10:19) | 1,792초 (29:52) | 3,129초 (52:09) | 없음 |

동일한 기본 수련 시작 조건에서 +5권 1회는 Gate10까지 330초, Gate30까지 330초를 절약한다. 반복 권 경로는 Gate30까지 5,895초를 절약하지만 +3권 1장과 +5권 5장이 필요하다. 이 경로도 관문 전투 3회를 모두 수행하며 전투 가정 시간 270초가 포함된다. 상품 가격과 ProductId가 없으므로 Robux 비용은 산정하지 않았다.

첫 무료 돌파는 45초로 목표 범위 안이다. 첫 관문은 무료 자동사냥+시설 가정에서 10:51로 8~15분 탐색 목표 안에 있다. 세 관문 기본 수련 127:25는 60~120분 탐색 상한을 넘고, 자동사냥+시설 54:11은 하한보다 짧다. 가정한 킬 속도·보스 시간이 실측되지 않았으므로 이 수치만으로 밸런스를 확정하지 않는다.

## 아직 확인되지 않은 항목

- PC/좁은 화면의 최신 UI 캡처와 실제 모바일·모바일 가로 화면. Windows 화면 도구가 초기화 오류를 내며 StudioCaptureService는 스크린샷 권한이 없어 캡처하지 못했다.
- 2인 레이드의 실제 BasicAttack·회피를 통한 전체 전투, 참가자 이탈·재접속, Dash/전투 전체 회귀와 실제 보스 처치 시간. 2인 보상 테스트의 피해는 테스트 서버가 EnemyService/RaidService에 직접 주입했다.
- 게시된 Experience의 DataStore 권한, 두 서버의 실제 세션 경쟁, Roblox 실제 영수증 전달. Studio 메모리 모의 저장으로만 확인했다.
- 실제 플레이에서 자동사냥·직접 플레이 킬 속도 및 Gold/분, 보스 전투 시간과 첫 관문 권장 장비 밸런스.

보이는 시연 창은 자동 테스트와 별개로 사용자가 직접 조작해 확인할 수 있도록 임시 빌드에서 실행했다. 화면을 제가 직접 보거나 캡처해 검사한 것으로 기록하지 않는다.

## 사용자가 Command Bar 없이 확인하는 10분 동선

1. Rojo 최신 빌드로 Studio Play를 실행한다. 왼쪽 HUD의 누적 수련력, Level, 돌파 단계와 초당 수련량이 증가하는지 본다.
2. 오른쪽 `성장` → `돌파`에서 `무료 +1단계`를 눌러 비용과 다음 속도를 미리 본 뒤 `돌파 확정`을 누른다. 소비 가능 수련력만 줄고 누적 수련력과 Level은 유지되는지 본다.
3. `AUTO`를 켜고 Slime 사냥 보상으로 Gold가 늘어나는지 본다. `가방`에서 드롭 장비가 생기면 선택해 착용하고 `캐릭터`에서 Attack/Defense를 확인한다.
4. `성장` → `시설`에서 Gold가 충분하면 업그레이드한다. Gold 차감과 기본 수련량/초 증가를 확인한다.
5. Studio 한정 `DEV` 메뉴에서 `수련력 +10K`, `+5 돌파권 1장`을 누른다. `성장`에서 권 사용 전후 배수와 단계 이동량을 확인한다. 관문 건너뛰기가 차단되는지 본다.
6. `레이드` → `관문 10 · 일반`로 들어가 보스 HP, 위험 범위, Q Dash를 확인한다. 실제 관문 기록을 얻으려면 10단계 도달 후 보스에 유효한 공격을 가하고 승리해야 한다.
7. 테스트가 끝나면 Play를 중지한다. 이 임시 Studio 세션의 프로필은 메모리 모의 저장이므로 다른 Studio 실행으로 영구 보존된다고 기대하지 않는다.

시연용 `tests/growth-v2-showcase.luau`는 임시 Rojo Place에서 30분간 Play를 열어 둔다. 원본 `IdleRaid.rbxl`을 저장하지 않는다.
