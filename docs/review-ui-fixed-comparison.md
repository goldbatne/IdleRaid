# UI 수정 빌드 Gate10 세 경로 비교

대상은 `build/IdleRaid-review-ui-fixed.rbxlx` (SHA-256 `81f97c73de0d348fbb43317695d854709243663f118ed9f74342e9e98f61218f`)이다. Roblox Studio 0.742.0의 **가상입력 자동 통합 테스트**이며 실제 사람 조작이나 결제가 아니다. 세 경로는 같은 빌드, 같은 초기 모의 프로필, 같은 `tests/review-matched-*.luau` 정책을 사용했다. 초기 단계 1, 시설 1, Gold 0, FinalAttack 10, 인벤토리 비어 있음, 기본 수련 ON이다. 차이는 무료(권 0장), +5권 1장, 10분 수련권 1장뿐이다.

가상입력 정책은 자동사냥, 첫 드롭 장비 비교·장착, Gold 충족 시 시설 2 구매, 돌파 가능 시 버튼 사용, Gate10 직접 입장, `RaidTelegraph` 기반 WASD/Q 회피다. +5권은 첫 돌파 가능 시 1→6에서 한 번 사용했다. 수련권은 첫 사냥 보상 직후 단계 1에서 한 번 사용했다. 수련권 지급 계산은 서버의 당시 기본 수련 속도 10/초 × 600초 = 6000 수련력이다. 사용 직후 스냅샷에는 자연 수련분이 함께 들어갈 수 있다.

| 경로 | 권 사용 단계/시점 | 관문 도달 (초) | 입장 대기 (초) | 보스 전투 (초) | 클리어 (초) | 결과 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| 무료 | 없음 | 294.311 | 5.100 | 98.678 | 398.290 | PASS |
| 모의 +5권 | 1단계 / 26.691초 | 180.686 | 5.120 | 106.826 | 292.831 | PASS |
| 모의 10분 수련권 | 1단계 / 5.109초 | 216.069 | 5.132 | 104.063 | 325.478 | PASS |

시간은 클라이언트 러너 시작부터의 경과시간이다. 입장 대기는 RAID 클릭 직전부터 서버 `Active`까지, 보스 전투는 `Active`부터 `Clear`까지다. 원본 로그에서 추출한 [CSV](review-ui-fixed-matched.csv), [무료 로그](test-logs/review-ui-fixed-gate10-free.studio.log), [+5권 로그](test-logs/review-ui-fixed-gate10-ticket5.studio.log), [10분권 로그](test-logs/review-ui-fixed-gate10-voucher10.studio.log)를 함께 제출한다. 세 로그 모두 `IR_MATCH_SERVER_RESULT <경로> true nil 10`과 `IR_MATCH_GATE_CLEAR`를 포함한다.

드롭과 전투 난수 시드는 고정하지 않았다. 실제 장비가 실행별로 달랐다(무료는 Training Sword 장착, +5권·수련권은 다른 드롭 경로). 따라서 위 시간 차이를 권의 순수 효과나 평균이라고 해석하지 않는다. 실제 모바일 입력, 인간의 보스 예고 판단, Gate20/30 실제 클리어는 이 비교로 검증되지 않는다.

기존 [성장 수식 비교](review-matched-play.md)의 레이드 중 기본 수련 누락은 수정되어 있다. 결정적 모델은 최상위 해금 Zone을 택하지만 실제 자동사냥은 가장 가까운 살아 있는 적을 고른다. 대상 선택 정책 차이는 남아 있으며, 위 표는 시뮬레이션 값이 아닌 수정 빌드의 실제 Studio 가상입력 로그다.
